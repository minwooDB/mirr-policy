mirr. 개인정보처리방침

최종 수정일: 2025년 6월 1일

mirr.(이하 "서비스")는 이용자의 개인정보를 소중히 여기며 관련 법령을 준수합니다.

1. 수집하는 정보

직접 입력 정보

  • 이메일 주소 (회원가입 시)
  • 피부 타입, 피부 톤, 관심 부위 등 선택 입력 정보 → 기기 내 로컬 저장, 서버 미전송

자동 수집 정보

  • 카메라 피드 (촬영 시 일시적 처리, 서버 저장 없음)
  • AI 분석 요청 시 이미지 (분석 후 즉시 삭제)
  • 광고 식별자 (GAID/IDFA, 맞춤 광고 목적)

2. 정보 이용 목적

  • 회원 인증 및 서비스 제공
  • AI 메이크업 분석 서비스 운영
  • 맞춤형 광고 제공 (무료 이용자)
  • 서비스 개선 및 오류 분석

3. 제3자 서비스

  • Supabase: 회원 인증 및 데이터 관리 (개인정보처리방침)
  • Google AdMob: 광고 제공 (개인정보처리방침)
  • Google Play: 인앱 결제 처리 (개인정보처리방침)
  • Apple Sign In: 소셜 로그인 iOS (개인정보처리방침)

4. 정보 보관 기간

  • 회원 정보: 탈퇴 시 즉시 삭제
  • AI 분석 이미지: 분석 완료 즉시 삭제
  • 로컬 저장 정보: 앱 삭제 시 자동 삭제

5. 이용자 권리

  • 개인정보 열람, 수정, 삭제 요청 가능
  • 광고 추적 거부 가능 (iOS: 설정 → 개인정보보호)
